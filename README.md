# Samir Aryan — Personal Portfolio

A responsive personal portfolio website showcasing my background, professional experience, technical skills, projects, and education.

## About

I’m Samir Aryan, a B.Sc. Computer Science and Information Technology graduate based in Kathmandu, Nepal. My interests and experience include web development, WordPress, website design, graphic design, video editing, IT management, and Computer Science education.

## Website Sections

- **About Me** — an introduction and professional focus
- **Experience** — work and teaching experience
- **Skills** — technical, creative, and interpersonal skills
- **Projects** — selected academic and web projects
- **Education** — academic background
- **Contact** — ways to get in touch

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Inter and Poppins)

The site uses responsive layouts and includes a light/dark theme toggle.

## Run Locally

No build tools or package installation are required.

1. Clone this repository:
   ```bash
   git clone https://github.com/WebdevSamir/mywebsite.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## Deploy with GitHub Pages

1. Open the repository’s **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. Wait for GitHub Pages to finish deploying and follow the published URL shown in the Pages settings.
